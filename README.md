# NOVA — Premium AI SaaS Website Template

## Live-demo build
This package is prepared for a public sales demo. It includes the cinematic motion layer, responsive layout, product showcase, FAQ, and license/pricing CTA structure.

## Before publishing
1. Replace `REPLACE_WITH_YOUR_PRODUCT` in `index.html` or `script.js` with your Gumroad product URL.
2. Deploy this folder as the NOVA live demo.
3. Record a 10–20 second hero/scroll demo for your marketplace listing.
4. Keep the included commercial license and documentation with the product download.

## Deploy
This is a static HTML/CSS/JS template. Upload the folder to a static hosting service such as Vercel, Netlify, or GitHub Pages.
